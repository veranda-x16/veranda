# Keyboard shortcuts

All of Veranda's keys on one page. Each program's own page has more
detail.

## Everywhere

| Key | Action |
|---|---|
| Alt+Tab | put the program aside and go to the desktop (see [The desktop](The-desktop.md#the-dock-and-alttab)) |
| Esc | close a box, a desk accessory, or a panel; cancel |
| Return | the default button of a box (OK, Save, Open) |

In Veranda's own programs, a menu's shortcuts are **Ctrl** and a
letter; **Alt** and the same letter works too.

### An open menu

In Veranda's own programs a click on a title opens its menu and it stays
open: move to an item and click it, or hold the button down, drag to the
item and let go. A click outside the menus closes it; moving along the
menu bar opens the menu of the title under the pointer.

| Key | Action |
|---|---|
| Up, Down | the item before or after |
| Return | choose it |
| Esc | close the menu |

The X16's keyboard sends some Ctrl keys as other keys: **Ctrl+Home**
arrives as Ctrl+PgUp, and **Ctrl+Down** as Ctrl+Q (which is Quit in some
programs). Use Ctrl+PgUp and PgDn instead.

On the desktop:

| Key | Does |
|---|---|
| Ctrl+O | Open the selected item |
| Ctrl+D | Duplicate it |
| Del or Ctrl+Backspace | Delete it (to the Trash) |
| Ctrl+I | Get info |
| Ctrl+P | Print |
| Ctrl+F | Find |
| Ctrl+R | Refresh the window |
| Ctrl+Up | Up a folder |
| Ctrl+N | A new window |
| Ctrl+W | Close the window |
| Home, Tab, Shift+Tab | Select the first, next or previous item |
| Esc | Select nothing |
| PgDn, PgUp | The next or previous page |
| F1 | Help |
| Ctrl+Q | Quit Veranda |

The menus show these keys at the right of their items.

### The Open and Save box

| Key | Action |
|---|---|
| Up, Down, PgUp, PgDn, Home, End | move the selection |
| a letter | (Open) the next name with that letter |
| Backspace | (Open) up a folder; (Save) delete a letter of the name |
| Return | Open or Save |
| Esc | Cancel |

## Network

**[Term](Term.md)**: every key goes to the host, except PgUp/PgDn
(scrollback), F7 (session menu), Alt+D dial, Alt+H hang up, Alt+X XMODEM
download, Alt+Q quit.

**[Veranda FTP](Veranda-FTP.md)**: Tab pane, Return open, F5 copy, F6
rename, F7 new folder, F8 delete, Esc stop.

**[Veranda Gopher](Veranda-Gopher.md)** and
**[Veranda Gemini](Veranda-Gemini.md)**

| Key | Action |
|---|---|
| Ctrl+L, or start typing | the address line |
| Ctrl+V | paste in the address line |
| Return | go; follow the selected link |
| Tab, Shift+Tab | (Gemini) the next, the previous link |
| Left, Right, Backspace | Back, Forward |
| Ctrl+R | Reload |
| Ctrl+F, Ctrl+G | (Gemini) Find, Find again |
| Ctrl+W | (Gemini) Wikipedia |
| S | (Gemini, a picture) save it |
| Esc | stop; leave the address line; back from a picture |

**[Veranda Chat](Veranda-Chat.md)**: Return send, Up/Down history, Tab

PgUp/PgDn scroll, End or Esc newest, Ctrl+V paste, Ctrl+Q quit.
