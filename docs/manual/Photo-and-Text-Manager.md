# Photo Manager and Text Manager

These two [desk accessories](Desk-accessories.md) keep **albums of
clipboard contents**, as GEOS's managers did.

- **Photo Manager** keeps pictures (Photo Scraps): for example parts of
  Paint pictures.
- **Text Manager** keeps texts (Text Scraps).

## The clipboard

When you **Copy** or **Cut** in a Veranda program, the picture or text
goes on the clipboard. Paint copies pictures; Veranda Edit, Veranda
Write, Veranda Calc, View, Term and others copy text. **Paste** takes it
back. The clipboard holds one picture and one text at a time. The
managers keep more.

## Use them

The window fills the screen: a title bar with the close box at its
right; a toolbar of buttons (**< Prev**, **Next >**, **Add**, **Copy**,
**Delete**); the page; and a status bar with the page number at the
left and what a button did at the right.

- **Add** puts the clipboard's picture (or text) into the album, after
  the page shown.
- **Copy** puts the page shown on the clipboard. Then paste it in a
  program.
- **Delete** takes the page out of the album.

| Key | Action |
|---|---|
| Left, Right | the previous, the next page |
| A | Add |
| C | Copy |
| D | Delete |
| Esc | close |

## Where the albums are

`Photo Album` and `Text Album` in `/VERANDA/.SYSTEM`. The clipboard
itself is kept there too. [View](View.md) can show a photo album.
