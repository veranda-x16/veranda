BEFORE THE VERSIONS: the packages of 2026-11-18 to 2026-11-21
(from the package 7b07106's README; 7b07106 is the last build before
Veranda 1.0, each section what came since the build in brackets)

BUILD 7b07106 (since 9277017)
  - Look 3 "Sunroom": the new default style (a sage desktop, white
    windows), colour icons for every program and document, labels that
    wrap (Gate Sans 9), About's text no longer clipped. Preferences >
    Theme still offers Classic, Graphite, Mint, Veranda; Dusk and Meadow
    are still there (with them, icons stay as before for now)
  - Veranda Ask: a refusal (401) no longer spends the sign-in; ASK.LOG
    keeps OpenAI's error messages. PC/chatgpt_signin.py --card ... --check
    signs in and sends one test question from the PC
  - the sign-in helper's browser page answers a little longer

EARLIER (since 45f356a)
  - Veranda Update (APPS): checks for a newer Veranda and fetches only
    the changed files (from GitHub releases, or your PC with
    PC/update_server.py); verified before anything is replaced, your
    files never touched, Undo last update. About this X16 shows the
    installed build
  - Veranda Ask: the sign-in's renewal fixed (it failed with "200: " and
    lost the sign-in). SIGN IN ONCE MORE from your PC. If anything fails,
    /VERANDA/.SYSTEM/ASK.LOG says why (no tokens in it). An unset clock
    no longer matters to it
  - Commander Write stage 2: paragraph styles (Style menu: Heading 1-3,
    Quote, bulleted and numbered lists; alignment, indents, spacing),
    Find and Replace (Ctrl+F, Ctrl+H), Word count, Go to page, Insert
    date and time; Page Down about 3x faster; about 192 KB documents
  - Veranda Gemini: web pages through NewsWaffle or your own proxy
    (PC/web_proxy.py); [Show image] shows PNG pictures; emoji as >> << *
  - Wikipedia: the Wikipedia icon in APPS, Go > Wikipedia (Ctrl+W), or
    "wp something" in Gemini's address line; File > Settings: language
    (pl for Polish). Bookmark lines to add to GEMINI.MARKS by hand:
      => gemini://gemi.dev/cgi-bin/waffle.cgi NewsWaffle
      => gemini://gemi.dev/cgi-bin/wp.cgi/ Gemipedia: Wikipedia
      => gemini://gemi.dev/cgi-bin/wp.cgi/featured Wikipedia: featured
  - Preferences' date and time: type into them, Save sets the clock, Now;
    the menu bar says "Set clock" while the clock is not set
  - Window shadows clean (one 8x8 card, dark in dark mode); list text
    centred in its rows

EARLIER (since c526cd9)
  - Veranda Claude and Veranda Ask: code in a reply has [Copy] [Save...]
    and, for BASIC, [Save .PRG] (LOAD and RUN it in BASIC). Code menu:
    Ctrl+K copies, Ctrl+E saves the last block; Copy last reply
  - Attach a file to a question (Ctrl+Shift+A, a name in /DOCUMENTS:
    .BAS, a BASIC .PRG, text, a Commander Write document); a later fixed
    version saves back over it (asked first)
  - Chats saved after every answer in /DOCUMENTS/Chats; Ctrl+L lists
    them: open, rename, delete, carry on. New no longer asks
  - Costs: tokens shown after each answer (and a price with a Claude API
    key); Settings > Conversation: Remember all / last 10 / last 4 /
    only this question, Compact (a short summary instead of old
    messages, by hand or automatic), old code sent as one line, short
    answers; Ctrl+Return asks the cheap model once
  - Gate Mono is a real monospaced font now (10 and 12), not boxes
  - Italic: the last letter's slanted top no longer cut off

EARLIER (since 92c95b0)
  - fixed: a window minimised to the belt came back half drawn (only its
    title, status line and coloured plates) and stayed on the belt
  - fixed: Alt+Tab did nothing on R49 (the ROM gives no key for it):
    now it puts the program on the belt
  - click the clock in the menu bar: Preferences with Date and Time;
    click the speaker: a volume slider and Mute (every native program)
  - Veranda Gemini (APPS): a Gemini browser (see VERANDA GEMINI)
  - Disk Tools and About this X16 (APPS)
  - Commander Write (APPS): the new word processor, stage 1

EARLIER (since 14d04bf)
  - Veranda Ask (APPS): a conversation with OpenAI's models, with your
    ChatGPT plan (Plus or Pro; signed in once from a PC with
    PC/chatgpt_signin.py, see VERANDA ASK above) or an OpenAI API key.
    Needs a Zimodem that knows ATCS, like Veranda Claude

EARLIER (since c05f421)
  - Veranda Claude (APPS): a conversation with Claude through the Wi-Fi
    card. Needs your own API key (console.anthropic.com, paid by the
    token; Max, Ultra and Team plans include monthly API credits) and a Zimodem
    that knows ATCS. Opus 5.5 by default; Sonnet 5.5 and Haiku 5.5
    (much cheaper) in Settings
  - Veranda Claude can also use your claude.ai plan: Settings > Server >
    "Claude Code on my PC", with PC/claude_bridge.py (at the card's top)
    running on a PC where Claude Code is signed in. No API key and no
    TLS needed for that

EARLIER (since 6287d29) - THE NETWORK
  - Veranda Gopher (APPS): a Gopher reader. Bookmarks open first
    (Floodgap, Veronica-2, Quux.org, SDF, Bitreich); menus with a coloured
    badge for each kind of item, texts, searches, downloads to /DOCUMENTS
  - Veranda Chat (APPS): an IRC client. Libera.Chat, SDF and EFnet on
    port 6667 to start with; set your nick on the Servers page first
  - Term: Connection > Connect... connects to a host itself (Telnet or raw
    TCP), with a Hosts list (/VERANDA/.SYSTEM/TERM.HOSTS: a few BBSes and
    Telehack to start with, not checked); typing AT commands still works
  - a refused connection now says so at once on the real card (the card's
    modem answers NO ANSWER, which the network code did not know)

BEFORE THAT (since 52ad5ef)
  - the desktop picture in full colour: Dusk and Meadow are now VERA 4 bpp
    tiles under the desktop (110 colours instead of one ink over a colour
    a card). The wallpapers are version 3 files; an old Meadow.cvt from
    before (version 1) shows the pattern instead - use the one here
  - colour chrome on the desktop: colour icons (folder, document, card,
    printer, trash), a gradient title band and rounded corners on the
    front window, the dock's plate rounded
  - the shell's message boxes (About, errors, Duplicate, Rename) with
    rounded corners and a title band
  - dark mode: the colour icons half as bright, so the light ink shows
  - Lighthouse Pinball and Harbour Walls in full colour (the table and the
    harbour drawn in VERA tiles, not 8 x 8 colour cards)
  - for programmers: the SDK's vr_pic (vrpic.h) gives any program a
    full-colour picture (tools/mkwall.py --tiles makes it)
  - Harbour Walls saves its high scores now (the release build forgot to)

ALSO NEW IN THIS BUILD (since 970cb50)
  - geoWrite opens Word .docx files (the Open dialog lists them) and
    saves them (File > Save as Word...): bold, italic, underline, sizes,
    alignment, indents, tabs, page breaks; tables as tab-separated lines
  - VeraBASIC faster (3.1x-5.2x the ROM's BASIC with integers), 3,052
    bytes for a program's names
  - no emulator registers ($9FB0-$9FBF) touched on hardware; VeraBASIC
    clears its overlay state at load
