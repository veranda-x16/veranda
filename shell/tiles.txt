# The shell's own tiles (Veranda Look 2, DECISIONS V77), the source of
# shell/tiles.h (tools/mktiles.py). A tile: 32 x 32 pixels, "#" ink, on a
# 4 x 4-card block of one paper colour (a palette entry of Look 2: paper,
# ink, chrome, sidebar, select, title, yellow, red, green, purple, orange,
# cyan, sky, sky2, hill, dusk), in a rounded frame the shell draws.
#
#   tile <name>      a tile: its name, then
#   for <what>       what it is for: "class <GEOS class>" (an application
#                    that cannot carry a tile of its own: the ports), or
#                    one of the shell's: folder, up, document, card,
#                    printer, trash
#   colour <name>
#   32 rows of 32 characters
#
# Veranda's own applications carry their tile in their file (app.hdr's
# "tile", docs/APPFORMAT.md); any other GEOS application's icon is shown
# centred on a chrome tile.
