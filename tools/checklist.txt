# The hardware checklist (docs/RELEASING.md): tools/release.sh puts it into
# the package's VERANDA/README.txt, the sections whose sources changed since
# the release before first, each marked NEW; the rest after them. Taken from
# tools/mkdist.sh's README (THE NETWORK CHECKLIST, THE HARDWARE CHECKLIST)
# and the checklists of the packages until 2026-11-21.
#
#   [<section>] <source> ...
#   - an item (its next lines indented), one "[ ]" on the card's list
#
# A source: a path of this tree (a folder or a file: changed when
# "git diff <the release before> HEAD -- <path>" is not empty), or
# sibling:<repository folder> (changed when the commit mkdist.sh built is
# not the one the release before was built from). Keep each item short and
# something a person can see on the X16.

  flicker, the menu bar clean

  Duplicate / Rename's box; an error box
